## Descripción
This [.tar file](https://challenge-files.cylabacademy.net/library/0fcc092f4e3d0027bc89f6de85e2b750462dca0a96c5643e38e5825e2da1c3d2/1000.tar) got tarred a lot.

## Solución
```
El reto consiste en un archivo comprimido estructurado como una muñeca rusa; `1000.tar` contiene `999.tar`, el cual contiene `998.tar`, y así sucesivamente 1000 veces hasta revelar el contenido original.

Para resolverlo rápidamente en tu webshell sin extraer cada capa a mano, ejecuta este bucle de Bash directamente en el directorio donde tienes el archivo `1000.tar`:

Bash

```
for i in {1000..1}; do
  tar -xf $i.tar
  rm $i.tar
done
```

**Desglose del script:**

- **`for i in {1000..1}`:** Crea un contador que desciende desde 1000 hasta 1.
    
- **`tar -xf $i.tar`:** Extrae silenciosamente el archivo actual (comenzando por `1000.tar`).
    
- **`rm $i.tar`:** Elimina el archivo que acabas de extraer. Esto es crucial en las webshells de CTF, ya que evita que el disco se llene con 1000 copias redundantes del archivo.
    

Una vez que el proceso termine (tomará unos segundos), ejecuta el comando `ls`. Verás que el último archivo extraído es una imagen llamada **`flag.png`** (junto con un archivo `filler.txt` de relleno). Puedes descargar esa imagen a tu máquina local para visualizarla y leer la bandera escrita en ella.
```
