## Descripción
If I told you a word started with 0x70 in hexadecimal, what would it start with in ASCII?
## Solucion
Convertir el numero hexadecimal a ASCII
- Usar una pagina web Hex to ASCII
- Usar una herramienta web como cyberhef
```
int(0x70)
chr(112)
picoCTF{p}
```
## Solucion 2
- Ir al sitio web rapidtables
  picoCTF{p}
